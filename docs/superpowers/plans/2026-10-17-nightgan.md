# nightgan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> Execution: native (the author implements every task in-session, then one fresh reviewer checks the whole
> branch). Because the author writes the code directly into the repository, this plan fixes interfaces, tests and
> order; implementation code is not duplicated here.

**Goal:** a latent-space transformer GAN (GAT + CAT + R3GAN + REPA recipe) that trains on one 16 GB GPU and ships
with data preparation, training, generation and evaluation tools.

**Architecture:** images are encoded once by a frozen SD-VAE; a transformer generator with mapping-network
modulation produces 4 accumulated stage outputs; a scale-wise transformer discriminator scores them at 4 latent
scales; RpGAN loss with finite-difference R1/R2, stage consistency and REPA alignment of D to DINOv2.

**Tech Stack:** Python ≥ 3.10, PyTorch ≥ 2.4 (developed on 2.14 / CUDA 13.0), diffusers (AutoencoderKL),
safetensors, pytorch-fid (InceptionV3), torch.hub DINOv2, pytest.

**Spec:** `docs/superpowers/specs/2026-10-17-nightgan-design.md`

## Global Constraints

- One GPU, 16 GB; must not rely on custom CUDA extensions; Linux/WSL2 primary, Windows works without `torch.compile`.
- Default resolution 256; 128 and 512 supported; `patch = latent_res / 16` by default (256 tokens).
- Defaults: AdamW β = (0.0, 0.99), wd 0, eps 1e-8; lr = `2e-4 · 768 / d`; mapping lr ×0.01; grad clip 1.0;
  γ = 0.1 with `γ/2·(R1+R2)`; aGP σ = 0.03 on 1/4 of the batch; λ_cons = 0.1, w = (1/3, 1/2, 1); λ_REPA = 1;
  DiffAugment `color,translation,cutout`, p = 1; EMA half-life 350 kimg with rampup 0.05; global batch 256.
- Checkpoints contain only tensors and primitives (`torch.load(weights_only=True)`); exported models are
  `.safetensors` + `.json`.
- Tests run offline without downloading weights (pixel autoencoder, fake feature encoder).
- Code MIT; do not copy GAT/MAE code (MAE is CC BY-NC); write own implementations.

## Review Focus

1. Dataset folders with RGBA / palette / grayscale / CMYK / 16-bit PNGs and EXIF-rotated JPEGs → converted to
   upright RGB, transparency composited on white (test in Task 7).
2. Corrupt or non-image files inside the dataset folder → skipped and counted in the summary, not a crash (Task 7).
3. Dataset smaller than the batch (e.g. 40 images, batch 256) → sampler wraps across epochs, training runs (Task 7).
4. Re-running `train` on an existing run directory with a different model config → clear refusal naming the
   differing keys, unless `--force-config`; training-only options (time, eval cadence) may change freely (Task 9).
5. Interrupted `prepare` (Ctrl+C, full disk) → the folder is not usable by `train` and the error says to re-run
   `prepare`; `meta.json` is written last (Task 7).

### Task 2: Transformer layers

**Files:** Create `nightgan/layers.py`; Test `tests/test_layers.py`

**Interfaces (Produces):**
- `RMSNorm(dim, affine=True, eps=1e-6)` — output dtype = input dtype even under autocast.
- `rope_freqs(coords: Tensor[N,2], head_dim, theta=100.0) -> (cos, sin)` each `[N, head_dim//2]`;
  `apply_rope(x[B,H,N,hd], cos, sin)` (rotate-half convention); rows with coords = NaN-free identity for cls via
  `cos=1, sin=0` rows supplied by the caller.
- `grid_coords(side, scale=1) -> Tensor[side², 2]` token centres in finest-grid units: `(i + 0.5)·scale − 0.5`.
- `Attention(dim, heads)`: qkv (bias), per-head RMSNorm on q, k, out proj (bias);
  `forward(x, rope=None, splits=None)` — `splits` = list of segment lengths → independent SDPA per segment.
- `SwiGLU(dim, hidden)`; `EqualLinear(in, out, lr_mult=1.0, bias=True)`; `sincos_2d(dim, side) -> Tensor[side², dim]`;
  `patchify(x[B,C,H,W], p) -> [B, (H/p)(W/p), p²C]`, `unpatchify(t, p, C, side) -> [B,C,side·p,side·p]`.

- [ ] Step 1: tests — RMSNorm keeps bf16 under autocast and matches fp32 reference (atol 1e-2); `Attention` with
  `splits=[a,b]` equals masked full attention (block-diagonal mask, math kernel, fp32, atol 1e-5); RoPE: rotation
  preserves norm, relative property `<R(p)q, R(p')k>` depends only on `p − p'`; patchify/unpatchify inverse;
  EqualLinear output equals Linear with scaled weight; sincos shape/values bounded.
- [ ] Step 2: fail. Step 3: implement. Step 4: pass. Step 5: commit `feat: transformer layers`.

### Task 3: Generator

**Files:** Create `nightgan/generator.py`; Test `tests/test_generator.py`

**Interfaces:**
- Consumes: Task 2 layers, `ModelConfig`.
- Produces: `Generator(cfg)` with
  - `mapping(z[B,z_dim], y[B] | None) -> c[B,dim]` (normalize-2nd-moment on z and class embedding, 2 EqualLinear
    lr_mult 0.01 + SiLU);
  - `forward(z, y=None, truncation=1.0, return_stages=False, update_avg=False)` → `[B,C,R,R]` or list of 4
    stage outputs (coarsest semantics first, all at full latent resolution, accumulated);
  - buffer `c_avg[max(num_classes,1), dim]`, updated with β = 0.995 when `update_avg`;
  - truncation StyleGAN convention: `c = c_avg[y] + ψ (c − c_avg[y])`, ψ = 1 → none;
  - `stage_blocks` = `[(k+1)·(depth//4) − 1 for k in range(4)]`; modulation `Linear(SiLU(c)) → 4·dim` (scale, gate
    for attention and MLP), xavier gain 0.1, bias 0; 4 output heads (RMSNorm no-affine, scale modulation, Linear).
  - optional `torch.utils.checkpoint` per block when `cfg.checkpointing and self.training`.

- [ ] Step 1: tests — output shapes for (latent 16, p1), (32, p2), (64, p4) and pixel mode (C=3); 4 stages, last
  equals `forward()`; outputs differ for different z (diversity at init: mean per-pixel std over z > 1e-3);
  conditional: different y → different output; truncation ψ=0 gives the same image for all z of a class;
  `update_avg` moves `c_avg`; checkpointing gives identical gradients.
- [ ] Step 2–5: fail → implement → pass → commit `feat: generator`.

### Task 4: Discriminator

**Files:** Create `nightgan/discriminator.py`; Test `tests/test_discriminator.py`

**Interfaces:**
- Produces:
  - `pyramid(stages: list[Tensor]) -> list[Tensor]` — stage k area-downsampled by `2^(3−k)` (k = 0..3); and
    `real_pyramid(x) -> list[Tensor]` (same resolutions from one tensor).
  - `Discriminator(cfg)`; `forward(scales: list[Tensor], y=None) -> (logits[B,4], hidden_finest[B, 1+T², D_dim])`
    — finest-scale cls + tokens of the last block, before the final norm;
  - `repa_project(hidden) -> (cls[B,repa_dim], tokens[B,T²,repa_dim])` (3-layer MLP, hidden 2048, SiLU);
    absent when `repa_dim == 0`.
  - Blocks: RMSNorm affine, Attention with `splits` = per-scale lengths, SwiGLU, LayerScale 0.1; shared
    patch-embed Linear(p²C → D_dim); per-scale learned scale embedding and cls (std 0.02); RoPE from
    `grid_coords(side_k, 2^(3−k))`, identity rows for cls; projection head
    `<Linear(RMSNorm(cls_k)), MLP(Embedding(y))>` (EqualLinear lr 0.01).

- [ ] Step 1: tests — shapes for the three resolutions; perturbing the scale-0 input leaves the logits of
  scales 1..3 unchanged (attention is block-diagonal); conditional logits depend on y;
  `repa_project` shapes; gradient flows to every scale input.
- [ ] Step 2–5: fail → implement → pass → commit `feat: scale-wise discriminator`.

### Task 5: Losses and latent augmentation

**Files:** Create `nightgan/losses.py`, `nightgan/augment.py`; Test `tests/test_losses.py`, `tests/test_augment.py`

**Interfaces:**
- `losses.py`: `rpgan_d(real, fake) -> scalar`, `rpgan_g(real, fake) -> scalar` (softplus, mean over batch and
  scales); `finite_diff_penalty(clean[B,S], noisy[B,S], sigma) -> [B]` = mean_s ((noisy − clean)/σ)²;
  `stage_consistency(stages, weights=(1/3, 1/2, 1)) -> scalar` (target `stages[-1].detach()`, mean over k of
  `w_k · mse`); `repa_loss(pred_cls, pred_tok, tgt_cls, tgt_tok) -> scalar`.
- `augment.py`: `AugParams` (tensors per sample: brightness, saturation, contrast, shift[B,2] int, cutout
  centre[B,2], per-op masks); `sample_aug(batch, side, policy, p, device, generator=None) -> AugParams`;
  `apply_aug(x, params) -> x` (latent space, zero padding for translation, cutout half size);
  `shift_images(img[B,3,H,W] uint8, params, latent_side) -> img` (translation × H/latent_side, zero fill) for REPA
  targets.

- [ ] Step 1: tests — RpGAN values against hand-computed softplus; `finite_diff_penalty` with a linear critic
  `D(x)=<w,x>` equals `‖w‖²` in expectation (fp32, many samples, rel 5 %); with the real discriminator in fp32
  its mean over 256 samples is within 15 % of the exact R1 (autograd, math SDPA); consistency zero when stages equal
  and no gradient to the last stage; REPA loss 0 for identical inputs, 2 for opposite; augmentation: p=0 is
  identity; translation by params moves a delta pixel by exactly `shift`; `shift_images` moves the matching pixel by
  `shift·H/latent_side`; same params applied to two stages transform them identically.
- [ ] Step 2–5: fail → implement → pass → commit `feat: losses and latent augmentation`.
